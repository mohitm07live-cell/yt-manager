Command Variables Cheatsheet

  • $(user) — Name of the user who triggered the command.
  • $(uptime) — Current elapsed stream duration (e.g. 1h 24m).
  • $(count) — Total number of times this command was used.
  • $(time) — Current local time.
  • $(query) — Extra arguments passed after the command.
  • $(random 1 100) — Generates a random number between range.
